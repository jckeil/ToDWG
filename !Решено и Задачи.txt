Решено:
0. Кликер работает только в Schemagee версии 3.5 (версия, на которую у Синтек есть лицензия)
1. Создание кликером из файла .sdd листов в формате .dxf с помощью штатной процедуры Экспорт
2. Каждый файл имеет уникальное имя в формате ИСХДНОЕ-ИМЯ-ФАЙЛА_листN.dxf
3. После завершения процедуры Экспорт выполняется процедура Объединение, с файлом на выходе в формате .dwg
4. Все страницы исходного файла располагаются в пространстве модели и в пространстве листов постранично (без настройки под виртуальный принтер для экспорта в .pdf).
5. Процедура объединение работает с листами формата А2 - типовыми для схем Э3.
6. В документе обрабатывается: замена шрифта на принятый в Синтек ISOCPEUR Italic (в пакете Windows идет по умолчанию isocpeui.ttf, но при отсутствии должен быть установлен самостоятельно в среду Windows)
7. Размер шрифта корректируется по условиям и выбран по ряду причин таким, каким выбран.



Проблемы и задачи:

Проблема1. Обратная связь для кликера невозможна. Если кликер зашел "не туда" то, продолжать слать команды будет, а результата не прибавится. Если ОС Windows не успела за командой кликера, то файла листа не будет. 
	
	Задача1. Добавить возможность экстренной остановки кликера в процессе выполнения им кода (горячие клавиши останова).
	Задача2. Блокировать мышь и клавиатуру после запуска процедуры Экспорт оставляя возможность только для нажатия горячих клавиш экстренной остановки. 

Проблема2. В случае ошибки конвертации и обнаружения ее Пользователем или кликером инициируется повторно процедура Экспорт (для случая, когда ОС Windows не успела за командой кликера и файлы листа(-ов) отсутствуют. Старая папка остается - это мусор, ее надо удалять, но спрашивать Пользователя.
	
	Задача3. Вести логирование, выполнять проверку созданных файлов. Выполнять повторно процедуру Экспорт. 
	Задача4. Добавить возможность удаления ненужных файлов, чтобы не было путаницы для Пользователя (с возможностью выбора удалять или нет).

Проблема3. Экспорт из DWG в PDF без настройки пространства листа невозможен. 

	Задача5. Определить возможность создания PDF через виртуальный принтер любого (из условного списка) разработчика ПО вируального принтера, либо через Публикацию средствами Autodesk по заранее заданным размерам листа (например всегда только А2, на весь лист).

Проблема4. Объединение происходит с отступом между листами заданной величины. Меняется формат - меняется величина отступа.

	Задача6. Определять реальный размер листа и суммировать с накоплением расстояние для вставки следующего листа.

Проблема5. Приложение работает в "тихом режиме" - неизвестен ход процесса и его результат.

	Задача7. Выводить понятный Пользователю отчет (с возможностью выбора)

Проблема6. Результат работы всех процедур сохраняется в фиксированную и жестко заданную папку "Рабочий стол" пользователя.

	Задача8. Добавить возможность выбора Пользователем места сохранения результата. 

Задача9. Объединить кликер и формирование файла DWG в один исполнимый файл. 
Задача10. Добавить возможность Drag&drop для файлов.
Задача11. Добавить возможность установки на Windows с возможностью автоматического обновления приложения по мере появления и устранения замечаний.
Задача12. Темная тема, 3 иностранных языка, рекламный баннер, кнопка для донатов, чат техподдержки с ИИ и т.п. не делать!
