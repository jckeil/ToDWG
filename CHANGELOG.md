# ToDXF — изменения

## v1.2 (в разработке)
Добавлено:
- **Прокрутка списка файлов колесиком мыши** внутри области; полоса
  прокрутки появляется только когда список выходит за границы.
- **Тёмная тема** — движковый переключатель «Темная тема»: мягкая,
  неконтрастная палитра (фон #2B2B2B, карточка #333333, текст #E6E6E6,
  приглушённый акцент); поля количества/формата и стрелки оформлены под
  тему, в т.ч. неактивные (серые) и выпадающие списки; поле количества
  листов остаётся тёмным и в неактивном состоянии.

Изменено:
- Тема применяется ко **всем окнам** (главное, прогресс, успех, ошибка,
  «Остановлено», сводный отчёт), а не только к окну выбора; вторичные
  кнопки в отчётах сделаны основными (синими) и отодвинуты от нижнего
  края — в тёмной теме больше нет «светлого на светлом».
- Исполняемый файл переименован в **`ToDXF.exe`** (без «v1» в имени —
  версия указывается в заголовке окна и в релизе GitHub).
- Зона перетаскивания и список файлов **объединены в одну область**
  (410×200): без файлов — «Перенесите сюда файлы .sdd», с файлами —
  список с прокруткой; переход бесшовный.
- Увеличены отступы между блоками; контент опущен ниже, чтобы движковый
  переключатель темы не перекрывал заголовок.
- Поле количества листов компактнее (по высоте как у поля формата).
- Перед первой командой Schemagee ждём подтверждения готовности (окно
  отвечает и нет модальных окон, до 60 с) — первая команда больше не
  «теряется» при медленном открытии документа; пауза после окна 2,5 с.
- Главный экран переработан по макету: заголовок и подзаголовок,
  кнопки «Выбрать файлы» / «Конвертировать» одного размера, опции под
  кнопками, красное предупреждение внизу, версия по центру.
- Тексты: «Выводить отчёт по завершении»; предупреждение
  «НЕ ИСПОЛЬЗУЙТЕ КОМПЬЮТЕР ДО ОКОНЧАНИЯ КОНВЕРТАЦИИ» и
  «ДЛЯ АВАРИЙНОЙ ОСТАНОВКИ НАЖМИТЕ CTRL+ALT+0».

## v1.1 — 10.11.2026 (предыдущий релиз)
Добавлено:
- **Формат листа**: A2 по умолчанию; галочка «Выбрать формат листа вручную»
  включает выбор A3/A4 и ориентации (горизонтальный/вертикальный).
  Размер листа применяется к layout'ам в DWG.
- **Очередь файлов**: перетащенные `.sdd` добавляются в список, запуск —
  кнопкой **«Конвертировать»** (активна, когда файлы выбраны). Больше нет
  автозапуска при перетаскивании: галочки можно выставить заранее.
- **Самовосстановление Schemagee**: если окно не отвечает, оно
  закрывается принудительно, файл открывается заново, лист повторяется
  (до 3 перезапусков на файл) — вместо бесконечного ожидания.
- Галочка **«Удалять .dxf файлы после конвертации»** (включена по умолчанию).
- Галочка **«Выводить отчёт о конвертации по завершении»**; для пакета
  показывается сводный отчёт по всем файлам.
- **Проверка конвертации после каждого листа** перед переходом к
  следующему: файл существует, не пуст, читается; при провале — повтор.

Изменено:
- Блок «Указать количество листов вручную» объединяет галочку и поле.
- Область перетаскивания выше и подписана «Перетащите сюда файлы .sdd».
- Подсказка: «Для аварийной остановки нажмите CTRL+ALT+0».
- Каждый файл в очереди можно удалить крестиком; кнопка
  «Конвертировать» подсвечивается синим, когда очередь не пуста.
- Окно компактнее (720×680), увеличена только зона перетаскивания.

Исправлено:
- Число листов больше не путается со страницами печати: диалог может
  показать 42 страницы при 7 листах (большая схема печатается на
  нескольких страницах). При расхождении со штампами «Формат А…»
  берётся число листов документа.

## v1.0 — 10.11.2026 (первая стабильная)
- Экспорт `.sdd` → DXF (Schemagee 3.5), имена `<ИМЯ>_листN.dxf`.
- Сборка альбома: схемы в модели + layout на каждый лист A2; шрифт
  ISOCPEUR Italic; коррекция размера текста.
- DXF → DWG (AutoCAD или ODA), отчёт в окне, `result.json`, лог.
- Экстренная остановка Ctrl+Alt+0, горячая клавиша работает всегда.
- Исправления: кнопка «Экспорт» в форме (DXF не создавался), зависание
  на сетевых путях, уход клавиш в окно прогресса, битые DXF Schemagee,
  кодировка (R12/cp1251), пустые DXF.
