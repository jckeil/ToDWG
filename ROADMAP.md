# ToDXF — план развития

## Ближайшее (v1.2)
- Выбор папки для результата.
- Очистка папок прошлых прогонов с подтверждением пользователя.
- Батч-режим из командной строки: `--batch ПАПКА` (все `.sdd` подряд).
- Закрывать AutoCAD, если его запускал сам конвертер.

## Среднесрочное
- Блокировка мыши и клавиатуры на время экспорта (с защитой-сторожем).
- Форма отчёта на выбор: окно / TXT / печать.
- PDF: публикация листов A2 средствами AutoCAD.
- Настройка пауз и таймаутов под медленные машины.
- Счётчики в `result.json`: повторы листов, починенные DXF.

## Дальше
- Установщик Windows и автообновление.
- Поддержка других версий Schemagee (после проверки на лицензии Синтек).
- Другие форматы листов (A1, A0), если понадобится.
- Тёмная тема, иностранные языки, баннеры, донаты — **не планируются**.
